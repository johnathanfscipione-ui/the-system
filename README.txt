THE SYSTEM — Life RPG v1

This is a FUNCTIONAL mobile web app/PWA prototype.
Features:
- Persistent XP, levels and ranks
- Daily quests
- Custom task creation
- Coins and reward shop
- Strength / Intelligence / Discipline stats
- Streak tracking
- Achievement tracking
- Mobile navigation
- Local save data
- Offline-capable service worker

To use on iPhone:
1. Put these files on a web host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the site in Safari.
3. Share -> Add to Home Screen.

This version intentionally uses an original anime-inspired System aesthetic rather than copying copyrighted characters.
